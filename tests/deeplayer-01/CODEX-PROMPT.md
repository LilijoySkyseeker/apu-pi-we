Today's lives everywhere count, rural and urban alike.

Classify each meaning: S (strong: clearly needs its own root), B (borderline: a general concept, but a reasonable case exists for a phrase or for leaving it out), P (a short phrase or existing root covers it: give it), X (too specific or specialist for a core vocabulary). Output only a TSV with header wold_id<TAB>meaning<TAB>class<TAB>note, one line per row, in input order.
