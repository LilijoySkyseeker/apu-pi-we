# Back-translation test 03: politeness

**Question:** can speakers be polite without blurring what they're doing? The documented failure in cockpits and operating theatres is a junior hinting where they should warn (`research/notes/politeness.md`).

**Method:** an original 10-line hospital scene: a greeting, polite requests, a polite warning, very polite advice to stop, an emergency with no politeness, an apology, a polite refusal, thanks and a farewell. A fresh blind reader got only the reference and the word lists; a fresh judge scored three axes.

**Result:**
- **Content: 19/20.** The one loss was a translator error: Claude's version of the emergency line left out the instruction "Stop!".
- **Act and urgency: 20/20.** The polite warning was read as a warning and the very polite advice as a clear recommendation. Politeness never weakened an act.
- **Politeness: 19/20.** "Would you mind…?" came back as "Please…". Still polite, but a notch more direct. The language can express the extra notch with **ku ku**; the translator used a single **ku**.
- The emergency's missing **ku** was read as urgency, not rudeness. The reader quoted the rule.

**Caveat:** the reader had the politeness section, which spells out these rules, so this tests whether the design *can* carry the distinctions. It doesn't test whether speakers would use it. Drift (**ku** inflating) is a prediction, not something a single test can show.
