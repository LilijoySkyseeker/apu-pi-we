# Egyptian Arabic → Apu Pi We

Speakers: أ = A (Karim), ب = B (Menna), ج = C (Omar), د = D (Salma), هـ = E (the clerk).

Names (tools/names.py): كريم kariːm → **kalimu**, منة menna → **menna**, عمر ʕomar → **omalu**, سلمى salma → **saluma**, أبو طارق abutaːreʔ → **abutale** (the restaurant, treated as one name). Loans from English: photo → **fowutowu**, photocopy → **fowutakapi**, stamp → **sutanpu**.

Politeness: Karim speaks to the clerk with **nun** where he says يا أستاذ / معلش, and **nun nun** where he says يا فندم / حضرتك. Friends and the clerk speaking down use no **nun**.

```
أ: يا جماعة أنا جعان موت، إحنا واقفين هنا من الساعة تسعة.
A: sonu la. a lon le kono gi momu nawi. pen le kolu mon kemu tan se mape po po.
friend PL. NONLIT I ONGOING die because want eat. we.incl ONGOING stand at place this from 9 0 0.
```
Note: جعان موت is hyperbole, so **a** (not literal) marks that sentence only. "Hungry" has no root; "want eat". إحنا here includes the listeners: **pen**.

```
ب: استحمل شوية يا كريم، فاضل قدامنا اتنين بس.
B: tin sefu fanse nin muyi eten, en kalimu. gun ewo na sa mon sinye pi pen.
INSTRUCT wait calm during time short, NAME Karim. there.is person ONLY two at front of we.incl.
```
Note: استحمل "bear it" has no root; rendered "wait calmly".

```
ج: اتنين إيه يا منة، الراجل اللي هناك ده ماسك ملف قد كده، ده هيقعد ساعة لوحده.
C: ba mu sa, en menna. lowu ben yonnu mabo la man gun woten fu tan. na wan bone awuwa fi.
EXCLAIM NOT two, NAME Menna. man that hold paper PL which is thick like this. ONLY he use hour one.
```
Note: the scornful rhetorical "two *what*" is carried as an exclamation "not two!"; the mockery of the echo-question is lost. ملف (file) = "papers". هيقعد (lit. "will sit") = "will use up". لوحده = **na wan** "he alone".

```
د: يا ساتر عليك يا عمر، دايمًا متفائل كده.
D: ba nosen yema pen se me, en omalu. a me pume gan ganin fu tan mon muyi we.
EXCLAIM god help we.incl from you, NAME Omar. NONLIT you think with hope like this at time all.
```
Note: يا ساتر (invoking God as "the Concealer/Protector") kept as a religious exclamation but as "God help us from you"; the specific divine epithet is lost. The sarcasm is marked with **a**.

```
ج: أنا واقعي يا سلمى، مش متشائم.
C: lon pume gan feko, en saluma, mu gan nuta.
I think with truth, NAME Salma, NOT with fear.
```
Note: no roots for realistic / optimistic / pessimistic; built as "think with truth / hope / fear" so turns 4 and 5 stay parallel.

```
أ: طب بقولكوا إيه، لما نخلص نروح ناكل عند أبو طارق؟
A: lon iko me la musu fi. wo pen fugi, min pen isi tun en abutale li nawi.
I tell you PL thing one. after we.incl end, Q we.incl go to NAME Abu.Tarek for eat.
```
Note: بقولكوا إيه ("I tell you what", a pseudo-question) rendered as a statement "I'll tell you something"; the discourse opener طب is not carried. The suggestion is a yes/no question, as in the source.

```
ب: كشري تاني؟ إنت ما زهقتش؟
B: min [كشري] moti. min me mu sin lewe mu tana bu.
Q [koshary] again. Q you NOT DONE become NOT enjoy it.
```
Note: koshary is a local dish, not an international/technical word, so not borrowed. "Fed up" built as "become not-enjoying"; **mu sin** "not yet" keeps the surprised negative question.

```
أ: الكشري مابيتزهقش منه، ده أسلوب حياة.
A: mon muyi fa, go lewe mu tana [كشري]. ba bu gun lite pi pata.
at time none, anyone become NOT enjoy [koshary]. EXCLAIM it is way of life.
```
Note: the impersonal مابيتزهقش uses generic **go**.

```
د: ماشي ماشي، بس المرة دي إنت اللي هتدفع.
D: isi, un mon gimu tan, na me unfu.
go, but at occasion this, ONLY you pay.
```
Note: ماشي answers by echoing the verb of Karim's proposal (**isi** "go"). The Egyptian doubling (ماشي ماشي = grudging concession) is not doubled, because doubling here would mean emphatic agreement; the grudging tone is lost. The cleft إنت اللي ("you're the one who") becomes **na me** "only you".

```
ب: يلا يا كريم، الشباك فضي، دورك.
B: tin yobe, en kalimu. pu yema lewe tapun. me isi eda.
INSTRUCT quick, NAME Karim. place help become empty. you go now.
```
Note: شباك (service window) = **pu yema** "place for helping"; used again in 16 and 23. دورك "your turn" = "you go now".

```
أ: صباح الخير يا أستاذ، لو سمحت كنت عايز أجدد البطاقة.
A: nun upe leso. so nun lon momu muge duwa mise pi lon.
POLITE good morning. REQUEST POLITE I want make new card of I.
```
Note: the honorific يا أستاذ has no address word (a role word would say "teacher"); carried by **nun**. The softening past كنت عايز ("I was wanting") can't be carried without saying it is really past; **nun** carries it.

```
هـ: صباح النور يا ابني. معاك البطاقة القديمة وصورة شهادة الميلاد؟
E: upe leso pi wino, tiwu lowu pi lon. min me ibe mise pani yen fowutakapi pi mabo pi tuko pi pata.
good morning of light, child man of I. Q you have card old and photocopy of paper of start of life.
```
Note: the reply formula صباح النور is kept as "good morning of light" to stay distinct from the greeting. يا ابني is affectionate, not kinship; **tiwu lowu pi lon** is as figurative as the Arabic. Birth certificate = "paper of the start of life".

```
أ: أيوه يا فندم، اتفضل، وجبت كمان صورتين شخصي احتياطي.
A: nun nun ibe. so nun nun yidu. lon wame sin dinyo fowutowu sa pi lon, don go wupi bu.
POLITE POLITE have. REQUEST POLITE POLITE take. I also DONE carry photo two of I, if anyone need it.
```
Note: أيوه = echo of **ibe** "have". اتفضل (offering) = "please take". احتياطي = "if anyone needs them".

```
هـ: لا الصور مش محتاجينها، إحنا بنصور هنا. بس الاستمارة دي ناقصها ختم.
E: din mu wupi fowutowu la, din fowutowu mon kemu tan. un mabo tan wupi sutanpu.
we.excl NOT need photo PL, we.excl photo at place this. but paper this need stamp.
```
Note: here إحنا excludes the listener (the office staff), so **din**, unlike **pen** in 1.

```
أ: ختم؟ معلش يا أستاذ، ختم إيه بالظبط؟ أنا آسف بس دي أول مرة أجدد لوحدي.
A: min sutanpu. nun sepi, sutanpu denku yu. lon sepi, un tan gun gimu pi fi man lon muge duwa bu gan ewo fa.
Q stamp. POLITE sorry, stamp correct what. I sorry, but this is occasion of one which I make new it with person none.
```
Note: معلش (light "excuse me") and آسف (sorry) both become **sepi**; the difference in weight is lost. بالظبط "exactly" = "which *correct* stamp".

```
هـ: ولا يهمك يا حبيبي. ختم النسر، من الشباك اللي في آخر الطرقة على إيدك الشمال.
E: tan gun mu bawe, sonu. sutanpu pi [النسر], se pu yema man gun mon fugi pi pu niba, mon funbe pi me.
this is NOT important, friend. stamp of [eagle], from place help which is at end of place walk, at left of you.
```
Note: يا حبيبي ("my dear", warm) = **sonu** "friend"; the endearment is weaker. "Eagle" has no root; "big bird" would lose which stamp is meant. Corridor = **pu niba** "path". على إيدك الشمال ("on your left hand") becomes "on your left".

```
أ: تمام يا فندم، متشكر جدًا. أختمها وأرجع لحضرتك تاني؟
A: nun nun lafi. bi lota. min nun nun lon sutanpu bu yen sigo tun me.
POLITE POLITE understand. very thanks. Q POLITE POLITE I stamp it and return to you.
```
Note: حضرتك (polite "you") = **nun nun** + **me**. تاني after أرجع is redundant in Arabic and dropped.

```
هـ: آه تعالى على طول، مش هتقف في الطابور تاني، هات الورقة ليا أنا.
E: sigo. tin obu fongo. me mu kolu sefu moti. tin neke mabo tun na lon.
return. INSTRUCT come straight. you NOT stand wait again. INSTRUCT give paper to ONLY I.
```
Note: آه = echo **sigo**. Queue = "stand waiting". ليا أنا (emphatic "to *me*") = "to only me".

```
أ: ربنا يخليك يا أستاذ، كتر خيرك.
A: so nun nosen kuwi me. so upe pi me lewe ke kudu.
REQUEST POLITE god keep you. REQUEST good of you become more big.
```
Note: both blessings are kept as wishes with **so** rather than flattened to **lota**. كتر خيرك is a thanks formula ("may your goodness grow").

```
ب: إيه يا كريم، خلصت؟
B: min sin fugi, en kalimu.
Q DONE end, NAME Karim.
```
Note: the opener إيه ("so, what's up") is not carried.

```
أ: لأ يا ستي، ناقص ختم. بس الراجل طلع ابن حلال وقالي مش هقف في الطابور تاني.
A: mu sin fugi, sonu. le wupi sutanpu. un o lowu gun ewo upe, yen iko lon wun lon mu kolu sefu moti.
NOT DONE end, friend. still need stamp. but SEEN man is person good, and tell I that I NOT stand wait again.
```
Note: يا ستي (teasing "my lady", marks the listener as female) = **sonu**; the gender and the mock deference are lost. طلع ("turned out") = **o**, firsthand. ابن حلال (lit. "son of the lawful", a religiously tinged idiom for a decent person) = **ewo upe**; the idiom is lost.

```
ج: شفتوا؟ مش قلتلكوا هنتأخر. أبو طارق هيقفل قبل ما نوصل.
C: min me la nagu. lon iko me la wun pen bone muyi netu, min. en abutale tapi ya pen liwon.
Q you PL see. I tell you PL that we.incl use time long, Q. NAME Abu.Tarek close before we.incl arrive.
```
Note: مش قلتلكوا (rhetorical negative question) = statement + tag **min** "…, right?". "Be late" = "take a long time".

```
د: يا عمر بطل نكد بقى وتعالى نمشي معاه للشباك.
D: tin bamo muge bayi pen eda, en omalu. tin obu. so pen niba gan wan tun pu yema.
INSTRUCT stop make sad we.incl now, NAME Omar. INSTRUCT come. REQUEST we.incl walk with he to place help.
```
Note: نكد (gloom, killjoy talk) = "making us sad". The impatient بقى is carried only as **eda** "now". **wan** = Karim, the one being talked about.

## Unclear rules

- **Vocatives.** Nothing says where an address (يا كريم) goes. Only a linker, scene-setter or if/when clause may precede the speech-act particle, so I put names after the first clause, and يا جماعة as its own sentence (**sonu la.**).
- **Address words.** Respect is "a role word before the name", but there is no guidance for address without a name (أستاذ, فندم, حبيبي, ستي, ابني), or for figurative kin/endearment terms.
- **Rhetorical questions.** Can **a** combine with **min** (a non-literal question)? Unstated; I avoided it.
- **Wishes / blessings.** Is **so** + third-person subject (**so nosen kuwi me**) an optative "may God…"? Only **so pen** "let's" is given.
- **Loans as verbs.** Position rule says any content word can be a verb; unclear if that holds for unlisted loans (**din fowutowu**, **lon sutanpu bu**).
- **Clock time before 10:00.** Is 09:00 **mape po po** or **po mape po po**?
- na after a relation word (**tun na lon**): "before a single word" presumably allows it, but not shown.
- **"Turned out" (mirative).** Whether **o** "seen" is the right source for something discovered by experience.
- nun with routines: whether **nun** goes before a greeting (**nun upe leso**) as "first in a statement".
- **Doubled answers**: Egyptian ماشي ماشي doubles for grudging concession; the doubling principle (widen/strengthen) seems to forbid copying it.
