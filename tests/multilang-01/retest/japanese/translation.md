# Japanese → Apu Pi We (multilang-01 retest)

Three friends, casual speech. Each block: Japanese, Apu Pi We, English gloss.
Gloss abbreviations: Q = min, REQUEST = so, ADVISE = fon, INTEND = de, EXCL = ba, CONF = kon, TOLD = fen, DONE = sin, ONGOING = le, SOON = win, FOCUS = fule, NAME = en, LOGO = sun, TOOL = du, AGENT = no, PL = la, EXCL.WE = din (we, not you), INCL.WE = pen.

```
A: ねえ、今週の土曜って空いてる？
A: mon dili pi ufo pi nelon tan, min me ibe muyi.
A: at day of 6 of week this, Q you have time.
```
ねえ is dropped: with no name, title or kin word to call B by, there is no address slot for it. The って topic becomes a fronted scene-setting phrase.

```
B: 土曜？んー、午後からならたぶん大丈夫。なんで？
B: min dili pi ufo. don wo leso, kon oma lon lenu. gi yu.
B: Q day of 6. if after morning, CONF 7 I can. because what.
```
んー (hesitation) has no word and is dropped. 午後 is "after the morning". たぶん is kon oma.

```
A: 健太が引っ越すじゃん。手伝ってくれる人探してるらしくてさ。
A: en kenta win kubo guyi, iwun. fen wan le walo geno ewo la man yema wan.
A: NAME Kenta SOON change house, as-you-know. TOLD he ONGOING try find person PL who help him.
```
じゃん → iwun (shared ground). らしい → fen. くれる: the benefit to Kenta is carried only by "help him". The speaker's in-group empathy and the softening さ are not carried.

```
B: え、もう引っ越すの？来月って言ってなかったっけ。
B: min wan win kubo guyi, donon. wan sin oyi wun wo dunan fi, min.
B: Q he SOON change house, surprisingly. he DONE say that after month one, right.
```
え + もう (sooner than expected) → donon on the question. っけ (half-remembered "wasn't it?") has no seeded word. language.md names it as a stance job still to grow, so the tag min carries it.

```
A: なんか大家さんの都合で早まったんだって。
A: fen dili pi kubo guyi sin lewe ke gelu gi ukun pi no ibe guyi.
A: TOLD day of change house DONE become more near because reason of AGENT have house.
```
んだって → fen. 大家さん: the さん is not carried, because lanno is defined for names and direct address, not role nouns (see ambiguous rules). なんか (vague filler) is dropped.

```
B: マジか、大変だね。で、何時から？
B: min feko. tan gun gofa, buni. yen, se muyi yu.
B: Q true. this is difficult, okay. and, from time what.
```
マジか is rhetorical surprise, rendered as the question "true?". ね (sympathy, inviting agreement) → buni.

```
A: 朝九時集合って言ってた。
A: wan sin oyi wun fanmu mon mape po po.
A: he DONE say that gather at 9 0 0.
```
朝 is dropped because the 24-hour clock label already says morning.

```
B: 九時はきついわ…午前中バイト入ってるし。
B: mape po po gun gofa, gi lon ibe doku nin leso.
B: 9 0 0 is difficult, because I have work during morning.
```
Contrastive は (nine, as opposed to the afternoon) is left to context, since fule is optional. Not carried: わ (soft assertion), the trailing …, and バイト's "part-time" sense (rendered as just doku).

```
C: 俺行けるよ。車も出せるし。
C: lon lenu isi. lon wame lenu obu gan tale.
C: I can go. I also can come with car.
```
俺 (rough, masculine "I") → lon, since there are no speech levels. よ is not carried. も and the listing し → wame.

```
A: え、ほんと？助かる！健太絶対喜ぶわ。
A: min feko. ba tan yema din. kon yawu en kenta lewe sogi.
A: Q true. EXCL this help EXCL.WE. CONF 10 NAME Kenta become happy.
```
助かる → din: it helps us, not C, who is the one helping. 絶対 is read as certainty (kon yawu), not as emphasis. わ is not carried.

```
C: でもさ、あいつの部屋って物多くない？前行ったとき本だらけだったじゃん。
C: un, guyi pi wan ibe musu feli, min. nin sin isi tun bu ya, bu kete gan ingo, iwun.
C: but, house of him have thing many, right. while DONE go to it before, it full with book, as-you-know.
```
あいつ (familiar, slightly rough "that guy") → wan, so the register is lost. 部屋 has no word and becomes guyi (home). 多くない？ → the tag min. じゃん → iwun. Who went is left unsaid, as in the Japanese.

```
B: あー、漫画やばかったよね。壁一面。
B: ba manga gun bi feli, buni. mon senmo minwe.
B: EXCL manga is very many, okay. at wall whole.
```
manga is a loan through names.py. あー (recognition) is dropped. やばい → ba + bi. よね → buni.

```
A: そうそう、だから段ボール足りないって嘆いてた。
A: feko feko. gi tan, wan sin oyi bayi wun du dinyo gun uyo.
A: true true. because this, he DONE say sad that TOOL carry is few.
```
そうそう → doubled echo (principle 5). 段ボール is du dinyo "thing for carrying", so "cardboard" is lost. 足りない: there is no word for "enough", so it becomes "are few". 嘆く → oyi bayi "say sadly".

```
C: スーパーでもらってくればいいじゃん。タダだし。
C: fon wan dunu bu la se supamakitu, iwun. bu la mu wupi nimo.
C: ADVISE he get it PL from supermarket, as-you-know. it PL not need money.
```
スーパー → supamakitu, borrowed from English "supermarket". ばいいじゃん → fon + iwun. タダ → "need no money", because enpa means free as in not held. The reason-giving し is not carried.

```
A: それ言ったんだけど、「めんどい」って。
A: lon sin iko tan tun wan, un wan oyi "doku bi feli".
A: I DONE tell this to him, but he say "work very much".
```
それ (C's suggestion just made) → tan. めんどい → "too much work". The bare って quote gets a say-verb (rule 12).

```
B: いや、引っ越しのほうがめんどいでしょ。
B: un, kubo guyi wupi doku ke feli, iwun.
B: but, change house need work more much, as-you-know.
```
いや → un, since there is no "no". でしょ → iwun. The standard of comparison is left out.

```
C: ほんとそれ。じゃあ俺、金曜の帰りにもらってくるわ。
C: tan gun bi feko. gi tan, de fule lon dunu bu la nin sigo mon dili pi te.
C: this is very true. because this, INTEND FOCUS I get it PL while return at day of 5.
```
俺、 as a contrastive topic → fule lon (I, since Kenta won't). わ is not carried.

```
A: さすが。じゃあ私、お昼なんか買ってくね。
A: ba me gun upe fu lon sin pume. gi tan, de fule lon bika pasu in, buni.
A: EXCL you are good like I DONE think. because this, INTEND FOCUS I buy food some, okay.
```
さすが → "you're great, as I thought". 私 vs C's 俺 → both lon. お昼 has no word for lunch and becomes "some food", which also covers なんか. The "bring along" in 買ってく is not carried. ね → buni.

```
B: バイト終わったらそっち直行するから、場所送っといて。
B: wo doku fugi, de isi fongo tun me la. gi tan, so sege kemu tun lon ya.
B: after work end, INTEND go straight to you PL. because this, REQUEST send place to me beforehand.
```
そっち → "to you all". といて (do in advance) → ya.

```
A: 了解、あとでLINEする。終わったらみんなでご飯行こ、健太のおごりで。
A: sege. de layin me wo. wo fugi, so pen we isi li nawi, yen en kenta unfu.
A: send. INTEND LINE you after. after end, REQUEST INCL.WE all go for eat, and NAME Kenta pay.
```
了解 → an echo, meaning understood (rule 4). LINE → layin, a brand loan used as a verb. おごり → "Kenta pays".

```
C: それ本人に言ってある？
C: min me sin iko tan tun fule wan.
C: Q you DONE tell this to FOCUS him.
```
本人 (the person himself) → fule wan.

```
A: 今から言う。
A: de win iko wan.
A: INTEND SOON tell him.
```

## [X…] symbols

None. Every concept was either composed (du dinyo "box", pasu in "lunch", doku bi feli "a hassle") or borrowed (supamakitu, manga, layin).

## Rules that were ambiguous

1. lanno with a role noun. Can lanno go before a role noun such as no ibe guyi, as Japanese さん does with 大家? language.md only gives it before a name or alone in address.
2. Stance after a question. Can a stance word follow a min question (min …, donon)? The examples only show it after statements.
3. ba with a stance word. Can ba combine with a stance word at the end (ba …, buni)?
4. Clock times before 10:00. Is 09:00 read mape po po or po mape po po? The examples are only 15:30 and 22:00.
5. Getting attention and hesitating without a name. There is no way to call for attention (ねえ) without a name or kin word, and no hesitation or recognition filler (んー, あー). mm means only "heard".
6. Where a du phrase ends. A modifier after du + verb can be read as part of the verb phrase (du dinyo uyo = "thing for carrying few"?). I used gun to close it.
7. Brand loans as verbs. Can a loaned brand name (layin) work as a verb the way native roots do?
8. Overlapping sentence-end words. じゃん/でしょ (iwun), ね/よね (buni) and 多くない？/っけ (min) were mapped by judgment. The seeded words overlap at the edges.
9. tan or ben. Should "that idea you just said" (Japanese それ) be tan (just said) or ben (the demonstrative example in rule 6)?
10. "Enough". There is no word or stated construction for "enough" / "not enough".
