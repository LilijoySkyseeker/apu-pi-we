# ap-base notes

Conventions: speaker labels kept and translated (`label:` on the first sentence of each turn; following lines of the same turn have no label). Bullets dropped, step numbers kept. Editorial `[cut]`/`[omitted]` notes left out. Interjections (hmm, ah), lol, `Rp`, `¥`, `UTC+9`, `CPU`, `[link]` and quoted foreign spellings pass through as notation. Named dishes and drinks (borscht, shashlik, vodka, tagine) are treated as names with **en**. `tools/check.py FILE` reports nothing on a plain `.txt` file (it only reads code blocks and bold spans), so each file was also checked wrapped in a code block. Every remaining flag is a later word of a multi-word name or one of the notations above.
