To pick up a package at a Cainiao station, you now have to install Taobao

Now at Cainiao stations, you need to read a code with Taobao to pick up a package, and this is many times faster than the old way, in which people used a number from a text message to pick up packages, but you must download Taobao to pick up a package, even if the package comes from Pinduoduo, Tmall, or some online shop.
A Wikinews reporter tried it and felt bad about having to use Taobao, and some shoppers think Taobao is big money that is taking over all of the trade.
