# The correlative grid as a completeness check (2026-10-15)

**Question** (author, 2026-10-15; Globasa review row 36): can every cell of the grid determiner × (person, thing, time, occasion, place, way, reason, kind) be said, and are the frequent cells short?

**Method:** each cell built from today's words (determiners **yu** which, **tan** this, **ben** that, **in** some, **bo** any/unspecified, **we** every, **fa** none, **eni** other, **kige** same; nouns **ewo** person, **musu** thing, **muyi** time, **gimu** occasion, **kemu** place, **lite** way, **ukun** reason, **niki** kind; relation words **mon**, **fu**, **gi** as the reference uses them, 4.8.3, 5.2.8), parsed in a frame with the formal grammar (`wan nagu X` for noun phrases, `wan obu X` for adverbial phrases). Frequencies: concept ranks from `tests/coverage-01/concepts.tsv`.

**Results:** all 72 cells parse. Frequency check (rung 5) on the cells English and the panel use most: **here** (rank 6) is **mon kemu tan**, **there** (39) **mon kemu ben**, both four syllables in three words; **then** (301) **mon muyi ben**; **where** (237) **mon kemu yu**, **when** (143) **mon muyi yu**, also four syllables. Already decided: always, often, sometimes, never get roots (inventory 2); **now** is a root (**eda**); **why** **gi yu** and **how** **fu yu** are short; someone/something/nothing are **ewo bo**, **musu bo**, **musu fa** (two words). Here and there are also on the Swadesh list (named across many families), so they pass both of the root tests (frequency and deep layer).
