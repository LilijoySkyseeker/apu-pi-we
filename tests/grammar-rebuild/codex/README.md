# Grammar-word frequencies without the English route (2026-10-15)

**Question** (author, decision 14; unknown-unknowns process risk 4): the grammar-word frequencies (`../frequency.tsv`) come from everyday equivalents in 15 languages that a Claude agent chose working from English glosses. Did that route bias the ranking the short-word rebuild relies on?

**Method:** Codex (a non-Claude model, gpt-6-astra, high reasoning; prompt `PROMPT.md`) supplied its own equivalents for the 74 meanings in the same 15 languages, told to think from inside each language's grammar and not to translate the English label, without seeing the original table (`equivalents-codex.tsv`). Both tables were scored the same way: median wordfreq Zipf over the languages with a separate word (`zipf.py`; the original script wasn't kept, so `zipf.py check` first reproduces `../frequency.tsv`: 73 of 74 identical, Spearman 1.000; Japanese and Korean are read from wordfreq's lists directly since their tokenizers aren't installed). This tests the English route and the Claude source together.

**Results** (`compare.txt`): Spearman 0.922 over all 74 meanings, **0.955 over the top 20**; the top 14 keep their order within two places (OF, AND, AT, TO, BE, FROM, NOT, FOR, THAT.comp …). The big movers are judgement rows, not English anchoring: rows measured in 0–1 languages (PLURAL, INSTRUCT, OBVIATIVE, PLACE: morphology-only, already flagged), NONE (23 → 53: the original counted plain negators such as *tidak*, *không* as "none"; Codex left them out), GENERIC (35 → 18: Codex counted generic *you*/*on*/*se*), INTEND, YOU (register: *tum* vs *aap*, *tu* vs *vous*).

**Verdict:** by the rule agreed beforehand (if the top ~20 keep roughly their order, the English route is fine for this use), no change to the frequencies the rebuild uses. The movers' current `grammar.tsv` frequencies already sit where either table would put them, give or take one tier (NONE 1, INTEND 2, GENERIC 3, THAT.dem 3, ALSO 4, YOU 8).
