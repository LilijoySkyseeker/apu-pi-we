## Notes on hard decisions

- **Register.** Bu/Pak → **lanno** (to and about a superior); A's and C's statements to Ratna carry **nun**; the A–C exchanges and Ratna's lines to staff have neither. "Ibu" used as a pronoun for the listener (12, 19) → **me** (the doc: no polite pronouns), with respect carried by **lanno** in address and **nun**.
- **Address position.** "Di folder "Laporan Q3" Sar, …" (6): the mid-sentence "Sar" moves to the end. Address goes only at the start or the end.
- **Stance.** *ya* (softening, inviting agreement) → **buni**; *dong ya* (14) → tag **min**; *kok* (6) → **a**; *deh* (16) → **buni**.
- **Times.** Indonesian speakers use the 12-hour clock in speech: "jam 3 sore" → **ka pi duwun**, "jam 1" → **mon fi** (the context is after lunch, so no part of the day is needed). *Sore* → **duwun**, *siang* → **minfi**. Weekdays use ISO numbering: Senin **dili pi fi**, Rabu **dili pi ka**, Kamis **dili pi da**, Jumat **dili pi te**.
- **"Paling lambat Jumat jam 3 sore"** (1). Friday is fronted as a scene-setting phrase so that "3 pm" can be the standard of **mu ke yodun se** "not later than". With a comma, a trailing **…, ka pi duwun** at the end of the sentence would read as an address.
- **Q3** (1) → **dunan ka pi ka**, meaning a three-month period labelled 3. Inside the folder name "Laporan Q3" it passes through as a file name.
- **Data** → **wifu la** "the numbers". The international form *data* would adapt to **data**, which begins with the digit syllable **da**, and the doc forbids that for content words.
- **Loans** (international forms run through the sound rules): coffee → **kofi**; graph/grafik → **gulafiku**. `names.py` gives the same forms. Neither is in the lexicon yet.
- **What check.py still flags:**
  - **mm**: a listed interjection.
  - **"Laporan Q3"** and **"draft"**: file names, which pass through.
  - **kofi** and **gulafiku**: loans made under the rules.
  - **[X1]**.
  - False positives on a few Indonesian, gloss and notes lines.
- **Built words:** rekap → **fanmu** "gather"; draft → **kemin man mu sin wonwe** "the document that isn't ready yet"; target → **ge keya wonku** "what must be reached"; follow up → **mido moti** "ask again"; lembur → **doku tason yodun** "work rather late"; mepet → **muge eten muyi** "make the time short"; dimarahin → **kegu bonko** "angry talk"; semangat → **upe doku** "good work", modelled on **upe isi**.
- **Iya** (15): there is no "yes", so the answer echoes the verb of 14's question: **keya**.
- **Wkwk** → **bubo** "laugh". **Cieee** → speech act **ba**; the 👀 carries the teasing.

## Markers

- **[X1]** *langsung*: "directly, myself, without a go-between (rather than through someone else or by message)". No existing word or relation covers it. **mu gan ewo eni** "without another person" misreads as "alone on the call".

## Rules I found ambiguous

- **Address vs. a fronted noun phrase.** The rule is that a short noun phrase plus a pause at the start is an address. That blocks openers such as "Satu lagi," ("one more thing"), so I used **gun fe musu fi.** The same reading threatens a time phrase after a comma at the end of a sentence.
- **Day plus clock time in one phrase.** The doc gives month plus day (**dunan pi yawu, dili pi mape**), but not weekday plus hour.
- **Q3 parse.** **dunan ka pi ka** could also parse as "month, three of three" (X **pi** Y = part of a whole).
- **lanno as a pronoun for the listener.** The doc says **lanno** alone can refer to someone and "marks the person, never the listener". It is unclear whether it may stand for *you*, as Indonesian *Ibu* does.
- **Stacking stance words.** *dong ya* wants both **a** and **min**; the doc doesn't say whether two stance words can follow each other.
- **Placing ya "beforehand" before a mon phrase** (11). It is unclear whether **ya mon …** would read as "before at …", so I moved the time phrase to the front.
- **upe + verb as a wish.** **upe doku** could be read as praise for work already done ("good work") instead of a wish.
- **Speech-act particle for a first-person request** (**so to … nagu** "let me see"). Only **so pen** "let's" is documented.
- **Emoji and the sentence boundary.** Where an emoji ends a sentence before another one starts (21), I added a full stop after the emoji.
