# Regression 01: group chat, English → Apu Pi We

Speakers write in a 12-hour (US) clock culture, so clock times pass through as `10`, `10:15`. Saturday is **dili pi ufo** (ISO weekday 6). Gloss uses the grammar.tsv labels; `3` after CONF = 3 in 6.

```
ok so are we still doing the lake saturday or what
A: gi tan, pen le isi tun nenwa mon dili pi ufo lu mu yu.
BECAUSE THIS, WE.incl ONGOING go TO lake AT day OF 6 OR NOT WH.
```
"ok so" = linker **gi tan**; "ok" has no word of its own (see the list at the end). "or what" = the which-question **… lu mu yu** "going or not, which?".

```
yes!! i've been looking forward to it all week
B: ba isi. to le sefu sogi nin nelon minwe.
EXCLAIM go. I ONGOING wait happy WHILE week whole.
```
"yes" echoes the verb (rule 4). "look forward" is built as **sefu sogi** "wait happily" (verb + manner).

```
im in but not before 10 lol
C: to isi, un mu ya 10, bubo.
I go, BUT NOT BEFORE 10, laugh.
```
"lol" goes to the stance slot as **bubo** "laugh" (an ordinary word in the stance position, as the stance section allows).

```
10 works. who's driving
A: 10 gun upe. ewo yu wungu tale.
10 BE good. person WH guide car.
```
"drive" is built as **wungu tale** "guide the car".

```
i can but my car only fits 4 and jake might come
B: to lenu, un tale pi to lenu dinyo na ewo da, yen kon ka en jake obu.
I can, BUT car OF I can carry ONLY person 4, AND CONF 3 NAME jake come.
```

```
wait jake's coming?? since when
C: tin sefu. ba min en jake obu. se muyi yu.
INSTRUCT wait. EXCLAIM Q NAME jake come. FROM time WH.
```
"??" (surprised question) is **ba min**, which the doc defines as the indignant question; it's the closest.

```
he texted me last night, he said maybe
B: wan tusi tun to mon yami pi afe. wan oyi "kon ka".
HE write TO I AT night OF yesterday. HE say "CONF 3".
```
"texted" is **tusi** "write"; the phone medium is left to context. "maybe" is quoted because the next message refers to the word itself.

```
lol jake's maybe means no
A: don en jake oyi "kon ka", wan yofu "mu obu", bubo.
IF NAME jake say "CONF 3", HE mean "NOT come", laugh.
```
There is no word for "no", so it echoes the verb: "not coming". "lol" moves to the stance slot.

```
facts
C: o feko.
FOCUS true.
```
**o** before the predicate insists the statement is true.

```
ok so i'll drive. pick you guys up at 10:15?
B: gi tan, de wungu tale. de yidu me la mon 10:15, buni.
BECAUSE THIS, INTEND guide car. INTEND take YOU PL AT 10:15, okay?
```
The question offering a plan is **de … , buni** "I'll …, okay?", not **min**.

```
perfect
A: bi upe.
VERY good.
```

```
can you get me first, i'm on the way
C: so yidu to ya. to gun mon sola pi me.
REQUEST take I BEFORE. I BE AT road OF YOU.
```
"can you" is a request, so it's **so**, not ability **lenu**. **ya** alone = "first" (rule 8).

```
yeah sure
B: de yidu.
INTEND take.
```
Acknowledgment by **de** + verb (rule 4).

```
should we bring food or just get something there
A: pen dinyo pasu lu na dunu musu in mon nenwa yu.
WE.incl carry food OR ONLY get thing SOME AT lake WH.
```
"there" = the lake, the destination of the whole plan. "should" (asking for advice) has no form: **fon** can't stand in a question, and **keya** "must" is too strong. Only the which-question carries it.

```
let's stop at the taco place on 5th
C: so pen bamo mon pu koda tako mon sola en 5th.
REQUEST WE.incl stop AT PLACE sell taco AT road NAME 5th.
```
**tako** is a loan (`names.py tako` → tako). "on 5th" is a bare place phrase, so it attaches to "stop" (rule 8). The meaning is the same, and a relative clause would have attached to **tako** (rule 15). The street name keeps its own spelling after **en**, with **sola** as its title.

```
omg yes
B: ba bi tayu.
EXCLAIM VERY agree.
```

```
hold on my phone keeps saying my storage is full and it won't load the map
A: tin sefu. liga pi to oyi moti moti wun pu kuwi pi to gun kete. yen bu mu dunu lunyu pi sola.
INSTRUCT wait. phone OF I say again again THAT.comp PLACE keep OF I BE full. AND IT NOT get page OF road.
```
"keeps saying" uses doubling to widen **moti moti** "again and again" (principle 5). "storage" is the listed compound **pu kuwi** "place for keeping". "load" is **dunu**, the doc's "download/get". "map" is built as **lunyu pi sola** "page of roads". A new sentence starting with **yen** keeps "it won't load" outside the **wun** clause.

```
just delete some of your 4000 cat pics
C: fon na nuton kin pi foto 4 000 pi [X1] pi me.
ADVISE ONLY remove PART OF photo 4000 OF [X1] OF YOU.
```
This is a suggestion that A turns down, so it takes **fon** (advise). **kin pi …** follows the part-of-whole pattern (**fi pi ka**). The final **pi me** could attach to [X1] ("your cat"), which barely changes the meaning.

```
never
A: mon muyi fa.
AT time NONE.
```

```
i'll send the address to the group, don't worry about it
B: de sege suso pi kemu tun funti. tin mu pume nuta.
INTEND send name OF place TO group. INSTRUCT NOT think fear.
```
"address" is built as **suso pi kemu** "name of the place", and "worry" as **pume nuta** "think fearfully". "about it" is left to context.

```
also sarah said she might meet us there around noon
C: en sarah fe sin oyi wun kon ka sun obu tun pen mon kemu ben fu minfi.
NAME sarah ALSO DONE say THAT.comp CONF 3 LOGOPHOR come TO WE.incl AT place THAT LIKE noon.
```
**sun** = Sarah inside her reported words. **kemu ben** "that place" keeps the English vagueness (the lake or the taco place). "Around" is **fu**.

```
nice. ok see you guys saturday
A: tan gun upe. nagu me la mon dili pi ufo.
THIS BE good. see YOU PL AT day OF 6.
```
"nice" is written as **tan gun upe**, because a bare **upe** could read as the greeting.

## Placeholders

- **[X1]** = cat (the animal). There is no root, and a description like the spider and frog compounds would not pick out a cat. It isn't a technical or international word, so it can't be borrowed.

## Rules found ambiguous

- **Discourse "ok"** (msgs 1, 10, 22): no word, no linker and no stance word fits an opener or closer meaning "alright then". **mm** means only "heard you". I folded it into **gi tan** or left it out.
- **Bare predicate fragments** (**bi upe.**, **o feko.**): rule 11 forbids leaving out the subject of **gun** but allows leaving out the verb. It's unclear whether **gun** and its subject can both go. I treated it as allowed.
- **fu minfi** "around noon": "about" is defined only for **fu** + a number.
- **Quantity determiner as head** (**kin pi foto** "some of the photos"): the part-of-whole pattern is given only with numbers.
- **Two pi phrases on one noun** (**foto … pi [X1] pi me**): no rule says which noun the second one attaches to.
- **ba min** is defined as an indignant question. Plain surprise ("??") has no listed form.
- **Can a relation word drop its object at the end of a clause?** Rule 8 allows it, but **mon** "there" before **fu**/**yu** would misparse, so I used **kemu ben** or the place name.
- **Writing "!!"/"??"**: allowed but "not needed". It's unclear whether doubling them (chat intensity) means anything. I left them out and used **ba**.
