# Third-party data

| File | Source | Licence |
|---|---|---|
| `offensive.tsv` | Wiktionary, via the kaikki.org machine-readable extracts (Tatu Ylonen, wiktextract). Entries tagged vulgar, offensive, slur or derogatory in 34 languages, used only to screen new words. | CC BY-SA 4.0 (Wiktionary content) |
| `concepts.tsv`, `concept-ranking.tsv` | CLICS4, the Database of Cross-Linguistic Colexifications (Tjuka, Forkel, Rzymski, List et al.), via its CLDF release. Coverage and lumping rates computed from it. | CC BY 4.0 |
| `../tests/grammar-rebuild/frequency.tsv` | Word frequencies from wordfreq (Robyn Speer), whose data combines several corpora. | CC BY-SA 4.0 (wordfreq data) |

Everything else in `data/` was made for this project and is public domain (CC0, see `LICENSE`).
